# DOMAIN: Platform

## 97. Auth aur privacy controls
- **Kya/Kaise:** Simple login (email magic link ya Google sign-in; ya anonymous + optional account). `users` table P0 ke 72 se extend. Privacy page, "meri saari data delete karo" button, consent checkbox (location, contacts).
- **Input:** login, delete request.
- **Output:** user-wise data isolation; delete par chats, trips, contacts, profile sab hat jaye.
- 🛑 **Verify:** Alag users ka data cross-leak nahi; delete ke baad DB me rows nahi (`sqlite3` se check); logout/login par history sahi.

## 95. Caching aur rate limiting
- **Kya/Kaise:** Maps/Weather/Tavily/Currency results ka TTL cache (SQLite ya `diskcache`): weather 1h, route 24h, currency 6h. Per-user rate limit (jaise 30 msg/10 min) aur daily token cap. Duplicate KB/translation calls cache.
- **Input:** repeated queries.
- **Output:** dusri baar fast response, API calls kam; limit par friendly "thoda ruko" message.
- 🛑 **Verify:** Same query 2 baar → log me "cache hit"; limit cross karo → message aaye, crash nahi; cost counter (calls/din) dikhe.

## 91. Streaming responses
- **Kya/Kaise:** Anthropic streaming API, Gradio me generator se token-by-token. Tool chalte waqt status line ("Weather dekh raha hoon...").
- **Input:** koi bhi message.
- **Output:** jawab 1-2 sec me aana shuru, lamba itinerary bhi dheere dheere likha dikhe.
- 🛑 **Verify:** Lamba plan maango, text stream ho; beech me "stop" dabao to ruk jaye; tool-using query me status dikhe.

## 92. Feedback loop
- **Kya/Kaise:** Existing like/dislike ko DB me save karo (`feedback`: session, turn, rating, comment, tools_used). Dislike par optional "kya galat tha" dropdown (galat info / bahut lamba / language / other).
- **Input:** 👍/👎 + reason.
- **Output:** `scripts/feedback_report.py` jo worst answers aur common reasons dikhaye.
- 🛑 **Verify:** 👎 dabao, DB row bane, report me dikhe; ek user ka feedback doosre ke chat se link na ho.

- **Output:** itinerary, food, budget jawab personalized.
- 🛑 **Verify:** "Veg hoon" save karo, food query me non-veg na aaye; profile edit/delete kaam kare; naye user par blank profile.

## 73. Saved trips aur favorites

- 🛑 **Verify:** Trip save, refresh/re-login ke baad dikhe; duplicate se alag copy bane; delete sach me hate.

# DOMAIN: Real-time

## 60. Opening hours aur closed-day warnings

## 59. "Near me" mode

- **Output:** 5 results (naam, distance, open/closed, rating) + map pin (B5 ke baad).
- 🛑 **Verify:** Real location par 3 results physically sahi; "open now" filter sahi; location deny par manual input.

## 41. Live two-way translation

- 🛑 **Verify:** Hindi↔English, Hindi↔Tamil full 5-turn chat; noisy audio par error message; latency <5 sec note; Sarvam fail par text-only fallback.

## 34. Area safety advice
- **Kya/Kaise:** KB category `area_safety`: raat me risky areas, solo/women tips, transport safety, crowd/pickpocket hotspots. Balanced tone, fear-mongering nahi.
- **Input:** "Varanasi me raat ko akeli ghoom sakti hoon?"
- **Output:** practical tips, avoid-list, helpline links, last_verified.
- 🛑 **Verify:** 10 cities ke tips 2 sources se match; stereotype/community-targeting nahi; sensitive jawab me disclaimer.

## 35. Medical help
- **Kya/Kaise:** Nearby 24x7 hospital + pharmacy (Maps), basic first aid cards (fever, diarrhoea, heatstroke, altitude, snake/dog bite), "doctor ko kab dikhao" red flags. Medicine dosage nahi dena (sirf general guidance + doctor).

- 🛑 **Verify:** Doctor/trusted source se first-aid cards review; dosage kahin nahi; emergency symptoms par seedha SOS suggest.

## 36. Lost passport/phone/wallet help

- **Input:** "Passport kho gaya".
- **Output:** numbered steps + kiska number + documents jo chahiye.
- 🛑 **Verify:** Har step ka link/number official source se verify; foreigner vs Indian ke alag flows.
