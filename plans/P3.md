# DOMAIN: Local Knowledge

## 53. Wildlife aur national park guide
- **Kya/Kaise:** KB per park: safari seasons, zones, tiger-reserve booking windows (info only), rules (no-plastic, silence), best time, gear. Ethical-tourism note.
- **Input:** "Ranthambore kab jaun?"
- **Output:** season, zones, rules, tips.
- 🛑 **Verify:** 8 parks ke closing seasons/rules forest dept site se; closed-season warning.

## 54. Trekking aur adventure info
- **Kya/Kaise:** Difficulty, duration, altitude, fitness, best season, permits, gear list, risks (AMS), guide-recommended notes.
- **Input:** "Kedarkantha trek kaisa hai?"
- **Output:** trek card (difficulty/days/altitude/season/permit) + packing + safety.
- 🛑 **Verify:** 8 treks ke numbers 2 sources se; safety disclaimer; high-risk treks par "guide lo" warning.

## 55. Pilgrimage-route planner
- **Kya/Kaise:** Circuits (Char Dham, Jyotirlinga, Shakti Peeth, Ashtavinayak) with order, distances, season, darshan/dress rules (50 se link), senior-friendly notes.
- **Input:** "Char Dham yatra plan".
- **Output:** ordered route + days + season + rules.
- 🛑 **Verify:** Circuit ke sahi sites aur sahi order; season/closure (winter band) sahi; respectful tone.

# DOMAIN: Info content

## 26. Driving rules aur permits
- **Kya/Kaise:** State-wise rules (hill driving, speed, parking), Inner Line Permit / protected area permit info, rental scooter tips (license/helmet).
- **Input:** "Ladakh me kaun se permit?"
- **Output:** permits + kahan milte + documents + official link.
- 🛑 **Verify:** Permit rules official source se (jo badalte rehte hain, to "verify" + date).

## 68. Customs aur baggage rules
- **Kya/Kaise:** Customs limits, restricted items (drones, antiques, medicines), cash declaration, domestic flight baggage norms.
- **Input:** "Drone le jaa sakta hoon?"
- **Output:** allowed/restricted + official link.
- 🛑 **Verify:** Official customs/DGCA page se; strong disclaimer.

## 70. Eco aur responsible-travel tips
- **Kya/Kaise:** Plastic-free, wildlife ethics, local-business support, temple/ghat cleanliness, over-tourism sites.
- **Input:** "Eco-friendly trip kaise karun?"
- **Output:** destination-specific tips.
- 🛑 **Verify:** Preachy tone nahi; tips practical aur sahi.

## 62. Time-zone aur jet-lag helper
- **Kya/Kaise:** IANA timezone calc, jet-lag adjustment plan (light/sleep), arrival-day light itinerary. (Medical advice nahi.)
- **Input:** origin country + India dates.
- **Output:** time difference + simple adjustment plan.
- 🛑 **Verify:** 5 country pairs ka offset (DST ke saath) sahi.

# DOMAIN: Budget aur Personalization

## 16. Group expense splitter
- **Kya/Kaise:** Group members, kisne kya diya, simple settle-up (sirf hisaab, payment nahi). Equal/custom split, minimal transactions algorithm.
- **Input:** "A ne 2000 diye hotel, B ne 800 khana, 4 log".
- **Output:** "B ko A ko X dena, C ko A ko Y".
- 🛑 **Verify:** 5 scenarios calculator se match; rounding paisa-level; sum zero check.

## 75. Trip journal
- **Kya/Kaise:** Daily auto-summary (itinerary + user notes + photos optional) → memory book; edit/export (PDF). Photos ke liye privacy consent.
- **Input:** notes/photos.
- **Output:** day-wise journal page.
- 🛑 **Verify:** User ke notes ke bahar fake details na jude; export sahi; delete option.

## 45. Learn-basic-words mode
- **Kya/Kaise:** 10-15 words/phrases ka mini lesson (greetings, thanks, numbers, food), audio, mini-quiz, destination ki local language (Marathi, Tamil, Bengali...).
- **Input:** "Kerala jaa raha hoon, thodi Malayalam sikhao".

- 🛑 **Verify:** Native speaker se words; audio uchcharan; quiz answers sahi.

# DOMAIN: Multimodal

## 79. Image-based inspiration
- **Kya/Kaise:** User photo upload → vision se vibe/features (beach, hill, heritage) → KB se similar destinations.
- **Input:** photo.
- **Output:** 3 similar destinations + kyun.
- 🛑 **Verify:** 10 alag photos par matches sensible; photo store na ho; copyrighted image ka misuse nahi (sirf analysis).

## 81. Photo gallery aur virtual preview
- **Kya/Kaise:** Destination ke legal images (Wikimedia Commons/open licence, attribution ke saath) gallery; optional 360/virtual tour links (official).
- **Input:** destination.
- **Output:** gallery with credits.
- 🛑 **Verify:** Har image ka licence aur attribution; koi copyrighted/stock image nahi; lazy-load, slow net par theek.

# DOMAIN: Community

## 86. Shareable trip cards
- **Kya/Kaise:** Itinerary highlight ko image card (HTML → PNG): route, days, budget range, Safarsathi branding. Personal info (naam, contacts, exact hotel) card me nahi.
- **Input:** trip_id.
- **Output:** social-ready image/link.
- 🛑 **Verify:** Hindi font sahi; privacy fields hidden; WhatsApp/Instagram par preview theek.

## 83. Traveler reviews aur tips
- **Kya/Kaise:** Users apne tips/reviews submit karein (place, rating, text), moderation queue (admin 96), spam/abuse filter, report button, helpfulness vote.
- **Input:** review form.
- **Output:** approved reviews place page/chat me "traveler tips" label ke saath (KB facts se alag dikhe).
- 🛑 **Verify:** Abuse/spam filter; admin approve ke baad hi publish; user apna review delete kar sake; fake-review basic check.

## 85. Ask-a-local Q&A
- **Kya/Kaise:** Verified locals/guides ka Q&A feed; question post → local jawab; moderation, local verification (phone/email + admin approval); jawab me "local" badge; AI draft suggestion optional.
- **Input:** question.
- **Output:** answer thread.
- 🛑 **Verify:** Unverified user "local" na ban sake; personal info leak nahi; moderation queue kaam kare.

## 84. Travel buddy finder
- **Kya/Kaise:** Opt-in profile (trip dates, destination, interests), matching, in-app chat. **High-risk feature:** strong safety (verified profile, report/block, no exact location sharing, meet-in-public guidance). Legal/privacy review ke baad hi launch.
- **Input:** buddy profile.
- **Output:** match suggestions + safe-chat.
- 🛑 **Verify:** Block/report kaam kare; data sirf opt-in users ko; minors ke liye restriction; safety tips onboarding me; **launch se pehle legal/privacy review.**

- **Output:** country-specific emergency, currency, KB, language.
