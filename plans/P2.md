# DOMAIN: Platform ops

## 96. Admin panel
- **Kya/Kaise:** Alag password-protected `admin` page: KB records add/edit/delete (form), `last_verified` update, validate + re-ingest button, feedback dekhna (92), scam/emergency number editor. Audit log (kisne kya badla).
- **Input:** admin login, record form.
- **Output:** code touch kiye bina KB update; change turant retrieval me.
- 🛑 **Verify:** Normal user admin URL na khol sake; record edit karke chat me naya jawab mile; galat schema save par validation error; audit log me entry.

## 93. Analytics dashboard
- **Kya/Kaise:** Anonymized metrics: popular destinations, intents/tools used, avg latency, error rate, "KB me nahi mila" queries (content gap!), 👎 rate, API cost/day. Admin page me charts.
- **Input:** logs + feedback DB.
- **Output:** dashboard + weekly CSV export.
- 🛑 **Verify:** 20 test chats ke baad numbers manual count se match; personal data (phone, location) dashboard me nahi dikhe.

# DOMAIN: Planning

## 7. Weekend getaway finder
- **Kya/Kaise:** User ki home city se X ghante ke andar ke KB destinations (Maps distance), season/budget filter.
- **Input:** "Nagpur se 4-5 ghante me weekend trip".
- **Output:** 5 options (distance, time, 2-day idea, best season).
- 🛑 **Verify:** Distances Maps se match; 3 cities ke result sensible; time-limit violate nahi.

## 11. Offbeat / hidden gems
- **Kya/Kaise:** KB tag `offbeat` per destination, "less crowded" alternatives to popular spots. Over-tourism/sensitivity note.
- **Input:** "Goa me bheed se door kuch".
- **Output:** 3-5 gems + kaise pahunchein + caution.
- 🛑 **Verify:** Gems sach me exist karte hain (Maps/2 sources); galat/band jagah nahi.

## 10. Festival aur event calendar
- **Kya/Kaise:** `data/events/` (festival, mela, date rules; lunar festivals ke liye year-wise dates). Itinerary dates se overlap detect. Crowd/closure warning.
- **Input:** destination + dates.
- **Output:** "Is hafte Navratri hai: bheed + kuch band, ye tips".
- 🛑 **Verify:** 10 festivals ki is saal ki dates official calendar se; overlap warning sahi trigger.
